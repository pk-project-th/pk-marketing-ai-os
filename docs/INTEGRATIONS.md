# External Integrations & Adapters

## Honest Integration Policy
The application never fabricates connection status. If credentials are not provided, features gracefully show "Integration not connected" or switch to prompt builder/local simulation modes.

## Adapters
1. **n8n Automation Engine**: Configured via `N8N_WEBHOOK_URL` and `N8N_API_KEY`.
2. **Google Workspace**: Google Drive, Google Sheets, Google Forms adapters.
3. **Media Generation**: Midjourney, Stable Diffusion, Imagen prompt generators with negative prompts and technical photography tags.
4. **Social Publishing**: Extension points for Meta, TikTok, YouTube, and X APIs.
