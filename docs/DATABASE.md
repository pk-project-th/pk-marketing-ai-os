# Database Schema & Relational Structure

## Relational Tables
- `profiles`: User accounts and roles
- `campaigns`: Marketing campaigns, objectives, budgets, timelines
- `products`: Automotive specifications, approved claims, and MSRP prices
- `content_ideas`: Structured ideas generated by Agent 01
- `content_assets`: Full production packages generated by Agent 02
- `creative_briefs`: Visual directions, lighting, and English prompts
- `repurposed_content`: Multi-platform tailored posts
- `documents`: Uploaded briefs and extracted raw text
- `document_fields`: Dynamic field mappings and confidence scores
- `form_templates`: Target form definitions
- `approvals`: Human-in-the-loop review queue
- `workflows`: Automation workflow configurations
- `workflow_runs`: Execution logs and payload traces
- `analytics_reports`: Campaign performance and 9-point diagnostics
- `knowledge_documents`: Brand and technical guidelines
- `ai_generations`: AI calls, token usage, latency, and costs
- `audit_logs`: Audit trail of consequential user and system actions
